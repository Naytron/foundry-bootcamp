# Support

Use a GitHub issue for reproducible workshop defects, broken instructions, or documentation gaps. Use GitHub Discussions for learning questions once the repository is published.

Before filing an issue:

1. Check `docs/troubleshooting.md`.
2. Run the local mock path to separate application issues from Azure access or quota issues.
3. Remove credentials, access tokens, subscription IDs, tenant IDs, and personal data from logs.
4. Include your operating system, Python version, failing command, and sanitized error text.

Azure subscription, billing, quota, or service incidents should be handled through the appropriate Azure support channel.
