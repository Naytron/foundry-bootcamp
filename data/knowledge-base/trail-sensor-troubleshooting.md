# Trail Sensor Connectivity Troubleshooting

If a Trail Sensor is offline:

1. Confirm the status light is on.
2. Move the sensor within 10 meters of the paired gateway.
3. Confirm the gateway has internet access.
4. Hold the sensor pairing button for three seconds. Do not hold it for more than ten seconds because that starts a factory reset.
5. In the Contoso Trail app, open **Devices**, select the sensor, and choose **Reconnect**.

If the sensor remains offline, record the status-light color and app error code. Do not ask the customer to open the enclosure. Draft a support case for Hardware Connectivity and include those observations.
