# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. When this repository is published on GitHub, use the repository's private vulnerability reporting feature.

Include the affected file or workflow, reproduction steps, impact, and any suggested mitigation. Do not include live credentials, customer data, or exploit traffic against systems you do not own.

## Supported content

The default branch is the supported workshop version. Preview Azure and SDK features are identified in the documentation and may change independently of this repository.

## Training deployment warning

The sample is not a production support system. Before production use, replace the workshop access token with Microsoft Entra authentication, use durable and tenant-aware state, apply network isolation, review data residency, and complete a formal threat model.
